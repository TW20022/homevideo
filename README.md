私人影库API采集系统

1. 前端： index.html
核心亮点：
原生播放引擎：基于 HLS.js + HTML5 <video>，告别加载失败。
自动化三剑客：详情页自动首集播放、5秒间隔断点续播、播放结束自动跳下一集。
自适应分类：修复了翻页后分类按钮消失的逻辑漏洞。
清理机制：一键清空浏览记录与后端缓存，保持系统清爽。

后端：api.php
核心亮点：
智能缓存：自动在临时目录创建缓存，大幅提升列表加载速度。
资源脱壳：自动在多条播放线路中精准筛选出 m3u8 直连地址，过滤干扰项。
防崩机制：包含错误屏蔽和 JSON 结构保护。

建议：
权限：如果运行报错，请确保 api.php 所在目录具有“写入权限”，以便它能存放缓存。
CDN 访问：如果按钮或排版偶尔变丑，请检查你的网络是否能流畅访问 lib.baomitu.com。
